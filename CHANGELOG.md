# Changelog

## 1.0.0 — 8 November 2026

First public release, distributed from GitHub releases and Orion Store.

- **56,946 churches worldwide** bundled from Wikidata (272,848 mapped church buildings thinned to one
  per ~11 km cell), with a live OpenStreetMap scan past street level.
- **Status colours:** green = meeting now, blue = already met today, red = not meeting yet. Live dots
  pulse; only live dots glow.
- **Community check-ins** — one tap marks a church as meeting, every open radar updates instantly over
  the realtime hub, a second person can confirm, and reports expire after 90 minutes.
- **Denomination view** and filters (Catholic, Orthodox, Anglican, Protestant, Baptist).
- **Android app** — Capacitor shell, package `app.churchradar.mobile`, release-signed APK for GitHub and
  Orion Store.
